# FocusFlow AI Video Avatar

## Overview

This project demonstrates a complete AI-powered video production workflow using multiple generative AI tools.

The objective was to create a short promotional video by combining AI-generated text, voice synthesis, music generation and a digital avatar.

---

## AI Tools

| Tool | Purpose |
|-------|----------|
| ChatGPT | Marketing script |
| ElevenLabs | AI voice generation |
| Suno | Background music |
| HeyGen | Digital avatar and lip sync |

---

## Workflow

1. Marketing script generation.
2. Voice synthesis.
3. Avatar creation.
4. Audio synchronization.
5. Background music integration.
6. Final video export.
